Some sequences you type on a target machine are always the same. Stepping into
a BIOS and walking to the boot order. Logging into an installer. The five
keystrokes at the start of an unattended install.

Macros do that in one click. A macro is a short script of three kinds of line:

- `key ctrl+alt+f2` - press a key chord;
- `type root` - type text, through the target's own keyboard layout;
- `delay 500` - wait half a second, because firmware menus need a moment.

Save it with a name in the Input panel and it appears as a button. Macros are
stored on the device, not in the browser, so they follow the KVM, not the
computer you happen to be sitting at.
