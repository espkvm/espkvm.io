Some things you type on a target are always the same. Getting into a BIOS and
walking to the boot order. Logging into an installer. The five keystrokes at the
start of an unattended install.

Macros do that in one click. A macro is a short script of three kinds of line:

- `key ctrl+alt+f2` - press a key chord;
- `type root` - type text, through the target's own keyboard layout;
- `delay 500` - wait half a second, because firmware menus need a moment.

Save it with a name in the Input panel and it appears as a button. Macros live
on the device, not in the browser, so they are there from whatever computer you
open the console on.
