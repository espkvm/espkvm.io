Translations

The console is written in English. These are the other languages it speaks, with how much of each is done. Each one can be read side by side with the English, or edited in the demo, where a change shows on the console at once and no device is needed.

Sending a translation

Before you start, open an issue saying which language you are translating, so two people do not do the same one. Check the open issues first: someone may already be on it.

"Export" in the editor saves the language as a JSON file. Open a pull request that adds it to web/locales/ in the console repository, or attach it to your issue. A partial file is fine: what is not translated shows in English. The file format and the rules for placeholders are in TRANSLATING.md.

A file can also be used before it is in a release: in the console, Settings, UI, Language, "From a file...", and "Keep on the device" makes it the language of every browser that opens that device.
